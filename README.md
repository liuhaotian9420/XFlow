# xyf-competition-mvp

Starter kit for vibe coding:
- Frontend: Streamlit
- Backend: FastAPI
- Package manager: uv
- Data libs: pandas, numpy

## Setup

```bash
uv sync
```

## Run Streamlit

```bash
uv run streamlit run app/streamlit_app.py
```

## Run FastAPI

```bash
uv run uvicorn backend.main:app --reload
```
